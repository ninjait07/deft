Windows habits, on your Mac.

Deft is a free, native menu-bar app that brings window snapping, live previews, and Windows-style keyboard behaviour to macOS — without changing anything permanently.

↓ Download for macOS View source
Free & open source · macOS 13+ · Apple Silicon · signed & notarized
What it does

Everything you missed from Windows

🪟

Windows Snap

Drag to edges and corners to snap. Snap Layouts, Snap Assist, shared resize dividers, and Win+arrow keys.

🔀

Live Preview switcher

Real, moving window thumbnails in Alt+Tab and Cmd+Tab, Snap Assist, and when you hover the Dock.

⌨️

Windows keyboard

Ctrl works as Cmd, the Win key, F-keys, Home/End, Explorer keys in Finder — with auto keyboard detection.

🇹🇭

Convert Layout

Typed “l;ylfu” instead of “สวัสดี”? Select it and double-tap Shift — Deft converts it and switches the input language, in any app.

🖱️

Mouse & scroll

Independent natural-scroll for mouse and trackpad, side-button back/forward, and Ctrl+scroll to zoom.

📊

System Monitor

Live CPU, RAM, and SSD activity right in the menu bar.

🖥️

Display controls

Resolution, refresh rate, rotation, main display, power a display off, and drag-to-arrange displays.

🧽

Clean Keyboard

Lock every key, Fn, and media button so you can safely wipe the keyboard.

Private by design

It stays on your Mac.

Deft collects nothing, has no accounts, no ads, and no tracking. It asks only for the macOS permissions it needs — and the code is open, so you can verify exactly what it does.

  • Accessibility — move and resize windows, translate shortcuts.
  • Screen Recording — draw live previews. Nothing is ever recorded or sent.
  • Input Monitoring — tell a Windows keyboard from a Mac one.
  • The only network use is checking for updates on GitHub.
Get started

Install in a minute

  1. Download the latest Deft.dmg from the releases page and open it.
  2. Drag Deft into your Applications folder.
  3. Launch Deft and grant the permissions it asks for.
