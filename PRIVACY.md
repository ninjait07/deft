# Deft — Privacy Policy / นโยบายความเป็นส่วนตัว

_Last updated: 2026-09-07_

## English

**Deft does not collect, transmit, or store any personal data.**

Everything Deft does happens locally on your Mac. To provide its features, Deft uses these macOS permissions:

- **Accessibility** — to move, resize, and read the position of windows, and to translate keyboard shortcuts. Deft only acts on windows on your own Mac; nothing leaves the device.
- **Screen Recording** — used only to draw live window previews (Alt+Tab / Cmd+Tab, Snap Assist, Dock hover). No image is ever recorded, saved, or sent anywhere.
- **Input Monitoring** — used only to tell a Windows keyboard from a Mac one for Auto Keyboard Detect. Keystrokes are never logged or transmitted.

**Network use:** Deft connects to the internet for exactly one thing — checking for a new version by reading a small public file (appcast.json) on GitHub. That request contains no personal data. Deft has no accounts, no analytics, no ads, and no tracking.

**Claude Code usage (optional):** when the AI Usage cell is on and the Claude Code command-line tool is installed, Deft asks that tool to run its own `/usage` command in the background — about every five minutes while you are using Claude Code, and when you open the monitor details. Claude Code then contacts Anthropic with its own sign-in, exactly as when you type `/usage` yourself, and saves the percentages on your Mac, where Deft reads them. Deft never sees your Claude sign-in, sends nothing itself, and the command uses none of your quota. Turn the AI Usage switch off to stop it.

**Donations** are handled entirely by third parties (your bank via PromptPay, or GitHub Sponsors). Deft never sees or stores your payment details.

## ไทย

**Deft ไม่เก็บ ไม่ส่ง และไม่บันทึกข้อมูลส่วนตัวใด ๆ**

ทุกอย่างที่ Deft ทำเกิดขึ้นในเครื่องของคุณเท่านั้น สิทธิ์ที่ขอใช้มีดังนี้

- **Accessibility** — เพื่อย้าย/ปรับขนาด/อ่านตำแหน่งหน้าต่าง และแปลงคีย์ลัด ทำงานกับหน้าต่างในเครื่องคุณเท่านั้น ไม่มีอะไรออกจากเครื่อง
- **Screen Recording** — ใช้วาดภาพตัวอย่างหน้าต่างสด ๆ เท่านั้น (Alt+Tab / Cmd+Tab, Snap Assist, ชี้ Dock) ไม่มีการอัด บันทึก หรือส่งภาพออกไปที่ไหน
- **Input Monitoring** — ใช้แยกว่าเป็นคีย์บอร์ด Windows หรือ Mac สำหรับ Auto Keyboard Detect เท่านั้น ไม่มีการบันทึกหรือส่งสิ่งที่พิมพ์

**การใช้เครือข่าย:** Deft ต่อเน็ตเพียงอย่างเดียวคือเช็คเวอร์ชันใหม่ โดยอ่านไฟล์สาธารณะเล็ก ๆ (appcast.json) บน GitHub คำขอนี้ไม่มีข้อมูลส่วนตัว ไม่มีบัญชีผู้ใช้ ไม่มี analytics ไม่มีโฆษณา ไม่มีการติดตาม

**การบริจาค** จัดการโดยบุคคลที่สามทั้งหมด (ธนาคารผ่าน PromptPay หรือ GitHub Sponsors) Deft ไม่เห็นและไม่เก็บข้อมูลการชำระเงินของคุณ
